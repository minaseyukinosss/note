# 90 天计划表

> 每天 1~2 小时。90 天约 13 周，分四阶段。每周对照本表，进入对应 [阶段目录](./README.md#四阶段结构)。
> 表里"实战任务"都要真写代码，"输出成果"是可验收的产物。

## 使用说明

- **强度**：工作日每天 1~2 小时（约 5 天/周），周末留 1 天复盘/补进度。
- **节奏**：每天 = 看阶段 README 对应小节（20 分钟）+ 写练习（40~80 分钟）+ 记笔记（10 分钟）。
- **验收**：每周末对照"输出成果"自查，做不到就顺延，不要硬推进度。

## 进度落后怎么办

- **优先保阶段三、四**：语法和高级特性可以边用边补，但工程能力和 async 是硬门槛。
- **砍进阶不砍主线**：每周"实战任务"是主线必做，笔记可以精简。
- **允许顺延**：90 天是理想节奏，做不完就延，不要跳过代码练习换取"表面进度"。
