# 源码阅读清单

> 读源码是从"会用"到"精通"的关键一步。原则：**从小到大、带着问题读、只读核心路径**。
> 不要一上来就啃 LangChain 全库——先从几百行的小库开始建立信心。

## 阅读方法（重要）

1. **先会用再读**：读某库源码前，先用它写过至少一个 demo，带着"它内部怎么实现的"这个问题去读。
2. **只读核心路径**：找到主入口（如 `Runnable.invoke`），顺着一条调用链读下去，别广度优先。
3. **边读边画**：把类继承关系、调用链画出来，比纯读有效。
4. **读测试**：一个库的测试用例是最好的"用法说明书"和"边界文档"。
5. **对照类型注解**：Python 源码靠类型注解表达意图，这也是阶段二要学好 typing 的原因。

## 推荐顺序（由易到难）

### 第 1 梯队：小而精（阶段二后就能读，几百到几千行）

| 项目 | 规模 | 读什么 | 学到的能力 |
| --- | --- | --- | --- |
| [`python-dotenv`](https://github.com/theskumar/python-dotenv) | 很小 | 如何解析 `.env`、如何注入环境变量 | 文件解析、简单 API 设计 |
| [`tenacity`](https://github.com/jd/tenacity) | 小 | `@retry` 装饰器如何实现、重试策略如何组合 | **装饰器 + 策略模式**（Agent 重试标配） |
| [`click`](https://github.com/pallets/click) 核心 | 中 | 装饰器如何构建 CLI、参数如何声明 | 装饰器进阶、DSL 设计 |
| [`instructor`](https://github.com/jxnl/instructor) | 中 | 如何用 Pydantic 把 LLM 输出变结构化 | **结构化输出的核心套路**，代码优雅 |

> 强烈建议第一个认真读 `tenacity`：它把装饰器、闭包、策略模式讲透了，且直接对应 Agent 的重试需求。

### 第 2 梯队：地基库（阶段三/四，理解框架依赖）

| 项目 | 读什么 | 学到的能力 |
| --- | --- | --- |
| [`httpx`](https://github.com/encode/httpx) | 同步/异步 client 如何统一、连接池、流式 | **async 设计**、优雅的 API 分层 |
| [`pydantic`](https://github.com/pydantic/pydantic)（v2） | `BaseModel` 元类魔法、校验流程、`Field` | 元类、描述符、运行时类型系统（重难点，选读） |
| [`openai-python`](https://github.com/openai/openai-python) | client 封装、重试、流式、类型化响应 | **LLM SDK 的标准设计**，直接可仿写 |

### 第 3 梯队：Agent 框架（阶段四，最终目标）

| 项目 | 读什么 | 学到的能力 |
| --- | --- | --- |
| [`smolagents`](https://github.com/huggingface/smolagents) | Agent 主循环、工具注册、代码执行 | **代码量小的完整 Agent**，最适合读循环逻辑 |
| [`pydantic-ai`](https://github.com/pydantic/pydantic-ai) | 类型安全的 Agent 设计、依赖注入 | 现代 Agent 框架设计、类型系统实战 |
| [`langchain-core`](https://github.com/langchain-ai/langchain) | `Runnable`、`__or__` 管道组合（LCEL）、`RunnableSequence` | **组合模式 + 协议设计**，理解 LCEL 本质 |
| [`llama-index`](https://github.com/run-llama/llama_index) | 检索管道、Node/Document 抽象、query engine | RAG 系统的工程组织 |
| [`fastapi`](https://github.com/fastapi/fastapi) / [`starlette`](https://github.com/encode/starlette) | 依赖注入、路由、async 请求处理 | **依赖注入模式**、ASGI |

## 带着问题读（示例）

读 `langchain-core` 时，别泛读，带这几个问题：

- `chain = prompt | model | parser` 里的 `|` 是怎么实现的？（找 `Runnable.__or__`）
- `Runnable` 是抽象类还是 Protocol？子类必须实现哪几个方法？
- `invoke` 和 `stream` 有什么区别？流式是怎么用生成器实现的？
- 同步 `invoke` 和异步 `ainvoke` 是怎么共存的？

读 `tenacity` 时：

- `@retry` 是带参装饰器，它返回的是什么？
- 重试策略（stop / wait / retry 条件）是怎么解耦成独立对象再组合的？
- 它怎么同时支持同步和异步函数？

## 阅读产出建议

每读完一个库，在对应阶段的 `notes/` 里写一篇 300~500 字的笔记，回答：

1. 它的核心抽象是什么（1~2 个关键类/函数）？
2. 主调用链是怎样的（用箭头画出来）？
3. 它用了哪个 Python 特性让代码变优雅（装饰器/生成器/魔术方法/typing）？
4. 有什么设计我可以搬到自己的 Agent 项目里？
