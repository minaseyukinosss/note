# Python for AI Agent 能力提升计划

> 面向**有 TypeScript / 前端工程经验**、正在做 AI Agent 开发的工程师。
> 目标不是从零学 Python，而是**补齐语言特性 + 工程规范**，最终能写工程级代码、读懂 LangChain / LlamaIndex 源码。

## 这套计划为谁而写

- 你已经会写 TypeScript / Next.js / React，理解闭包、异步、模块化、类型系统。
- 你在写 Python AI Agent 时，卡点不在"逻辑"，而在"这个语法/惯用法我不确定对不对"。
- 你能读英文文档、会用 Git、会调 LLM API。

如果符合，这份计划会帮你**跳过初学者内容**，直接补差异点和工程能力。

## 学习目标（90 天后应达到）

- 能独立设计并实现一个工程级的 AI Agent 应用（分层、配置、日志、测试齐全）。
- 能逐行读懂 LangChain Core（Runnable / LCEL）、Pydantic、FastAPI 的核心代码。
- 写出的 Python 代码符合 PEP 8、有类型注解、能通过 ruff + mypy 检查。
- 熟练使用 async / asyncio 做并发 LLM 调用与流式输出。

## 使用方式

1. 先读一遍 [01-背景分析](./01-背景分析.md) 建立心智模型；**之后日常学习不再对照 TS，一律"概念 → 直接写 Python → 跑通验证"**。
2. 每周对照 [03-90天计划](./03-90天计划.md) 的表格，进入对应阶段目录。
3. 每天 1~2 小时：**先看阶段 README 的讲解 → 写 `code/` 练习 → 把结论记进 `notes/`**。
4. 不要只读不写。每个知识点都要有一段能跑的代码验证。

## 环境要求

- Python ≥ 3.11（推荐 3.12，很多类型语法在新版本才完整）。
- 包管理直接上 [`uv`](https://github.com/astral-sh/uv)（比 pip / poetry 快且现代，见阶段三）。
- 编辑器装 Pylance（VSCode）或 Pyright，打开类型检查，边写边看类型提示。
