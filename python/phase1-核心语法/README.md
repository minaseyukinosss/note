# 阶段一：Python 核心语法强化（Day 1-21）

> 目标：补齐 Python 特有的数据结构惯用法、函数设计和陷阱，**跳过通用编程概念**（变量、循环、条件你已经会了）。

## 本阶段解决什么问题

你写 Python 时的卡点不是"不会循环"，而是：
- "这个应该用 list 还是 tuple？dict 怎么优雅地取默认值？"
- "为什么我改了传进去的 list，外面的也变了？"
- "`*args`、`**kwargs` 到底怎么用，源码里全是这个。"

本阶段就是把这些**惯用法和陷阱**一次性讲清。

## 学习顺序

1. **数据类型与真值**（Day 1-2）：`None`、真值规则、`is` vs `==`、可变 vs 不可变。
2. **序列与映射**（Day 3-5）：list / tuple / dict / set 的惯用法、切片、推导式。
3. **函数设计**（Day 8-11）：默认参数、关键字参数、`*args`/`**kwargs`、作用域、闭包。
4. **异常与模块**（Day 15-20）：`try/except`、自定义异常、EAFP、import 机制、包结构。
5. **综合实战**（Day 21）：JSONL 日志分析 CLI。
