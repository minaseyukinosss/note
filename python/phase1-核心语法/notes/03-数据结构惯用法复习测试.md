## 一、判断题（对 / 错，并一句话说明理由）

1. `[] == False` 的结果是 `True`。
2. `if not []:` 会进入 `if` 分支。
3. `0` 是假值，所以 `0 == False` 一定为 `True`。
4. 比较两个整数是否相等，应优先用 `is` 而不是 `==`。
5. `x is None` 比 `x == None` 更符合 Python 习惯。
6. `a = [1]; b = a; b.append(2)` 之后，`a` 仍然是 `[1]`。
7. 把 list 传给函数并在函数内 `.append`，函数外的原 list 不会变。
8. `int`、`str`、`tuple` 是不可变类型；`list`、`dict`、`set` 是可变类型。
9. `return name, age` 实际返回的是一个 tuple。
10. `([1, 2], 3)` 可以作为 dict 的 key。
11. `([1, 2], 3)` 和 `(1, 2, 3)` 都可以作为 dict 的 key。
12. `xs[-3:]` 在 `xs` 长度不足 3 时一定会报错。
13. `xs[::-1]` 会修改原列表。
14. `d["timeout"]` 在 key 不存在时返回 `None`。
15. `d.get("timeout", 30)` 在 key 不存在时返回 `30`。
16. `set([1, 2, 2, 3])` 的结果是 `{1, 2, 3}`。
17. list 的 `x in items` 和 set 的 `x in items` 平均时间复杂度相同。
18. `[m["content"] for m in messages if m["role"] == "user"]` 和普通 `for` 循环在功能上等价。

## 四、简答精要

### 1. `==` 和 `is` 的区别

- **`==`**：比较**值**是否相等。整数比较用 `==`。
- **`is`**：比较是否**同一对象**。判断 `None` 用 `is None`，不用 `== None`。

### 2. `==` 和 `not` 的区别（易混）

- **`==`**：问「两个值相等吗」。`[] == False` → `False`。
- **`not`**：问「是不是假值」。`not []` → `True`。
- 假值（falsy）≠ 等于 `False`：`0 == False` 为 `True`，但 `[] == False` 为 `False`。

### 3. `0 == False` 为什么成立？只有 0 吗？

`bool` 是 `int` 的子类，`False` 就是数值 `0`，`True` 就是 `1`。`==` 做数值比较时：

| 表达式 | 结果 |
| --- | --- |
| `0 == False` | `True` |
| `0.0 == False` | `True` |
| `1 == True` | `True` |
| `[] == False` | `False` |
| `"" == False` | `False` |

### 4. Python 传参传的是什么？

1. 传的是**对象引用**（贴标签），不是拷贝整个对象。
2. 对**可变对象**（list / dict / set）原地修改（`append`、`d[k]=v`），调用方手里的同一对象也会变。
3. 对**不可变对象**（int / str / tuple），赋值只会让局部变量指向新对象，不影响调用方原来的引用。

### 5. 可变 vs 不可变

| 不可变（不能原地改） | 可变（可以原地改） |
| --- | --- |
| `int`, `float`, `str`, `tuple`, `frozenset` | `list`, `dict`, `set` |

- 不可变：`s += "!"` 会创建新字符串，不是改原串。
- 可变：`a.append(3)` 直接改原 list，id 不变。

### 6. tuple 和 list 分别什么时候用？

- **tuple**：固定结构、函数多返回值、当 dict key（不可变 → 可哈希）。
- **list**：元素会增删改的序列（如 Agent 的 `messages` 不断 `append`）。
- **list 不能做 dict key**：dict key 须可哈希；list 可变，内容变了哈希就不稳定，Python 直接禁止（`TypeError: unhashable type: 'list'`）。

### 7. 切片 `xs[start:stop:step]`

- `start`：从哪开始（**含**）
- `stop`：到哪结束（**不含**）
- `step`：步长；`-1` 表示倒序
- 切片**不越界**，返回**新列表**，不修改原列表

链式切片从左到右执行，例如 `xs[::-1][:3]`：

```python
xs = [10, 20, 30, 40, 50]
xs[::-1]       # → [50, 40, 30, 20, 10]  整表反转
xs[::-1][:3]   # → [50, 40, 30]           再取前 3 个
```

### 8. `d.get(k, default)` vs `d[k]`

- **用 `.get`**：key 可能缺失、缺了不应崩溃（解析 API 响应、读配置）。
- **用 `d[k]`**：key 必须存在，缺了说明逻辑有问题，应该抛 `KeyError`。

### 9. list vs set 的 `in` 复杂度

- list 的 `in`：O(n)，逐个遍历。
- set 的 `in`：平均 O(1)，哈希查找。
- Agent 维护「已访问集合」用 set，因为会高频 `if x in visited`。

### 10. 推导式 vs `for` 循环

功能等价，推导式适合单一目标的「过滤 + 转换」：

```python
# 推导式
[m["content"] for m in messages if m["role"] == "user"]

# for 循环
contents = []
for m in messages:
    if m["role"] == "user":
        contents.append(m["content"])
```

逻辑分支多、步骤多时用 `for` 更清晰。

## 六、复盘总结（本次测试易错点）

| 知识点 | 易错表现 | 正确理解 |
| --- | --- | --- |
| 假值 vs `== False` | 以为假值都等于 `False` | `0 == False` 为真，但 `[] == False` 为假；判空用 `not x` |
| `==` vs `not` | 混为一谈 | `==` 比值；`not` 判真假值 |
| 切片 `[start:stop:step]` | `xs[1:5:2]` 写成 `[0,2,4]` | 先定范围 `[1,5)`，再 step=2 → `[1,3]` |
| `xs[-2:]` | 写成 `[50,40]` 反转顺序 | `[-2:]` 保持原顺序 → `[40,50]` |
| `xs[::-1][:3]` | 漏掉链式执行 | 先全反转，再取前 3 个 → `[50,40,30]` |
| 可变对象共享 | 默认参数第二次输出 `[2]` | `bucket=[]` 只创建一次，第二次是 `[1,2]` |
| dict 取值 | 以为 `d[k]` 缺 key 返回 `None` | 缺 key 抛 `KeyError`；安全读取用 `.get` |
