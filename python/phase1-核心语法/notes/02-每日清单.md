## Week 1：数据结构惯用法（Day 1-7）

### Day 1 — 真值规则 + None + `is` vs `==`

- [x] 读 `[../../01-背景分析.md](../../01-背景分析.md)` 的"避坑提醒"第 1、5 条。
- [x] 实验：在 REPL 里跑 `bool([])`、`bool({})`、`bool(0)`、`bool("")`、`bool(None)`，确认都是 `False`。
- [x] 实验：`a = 1000; b = 1000; print(a is b, a == b)`，理解 `is`（同一对象）vs `==`（值相等）。
- [x] 做题 **1** `is_empty`，取消断言跑通。

- 记录：`if not x:` 会把哪些值当空（`[]` / `{}` / `""` / `0` / `None`）？
以上都是假值（falsy），`if not x:` 都会进分支。另外 `False` 也是假值。有内容的容器和非零数字为真。`[] == False` 为假，但 `not []` 为真。



### Day 2 — 可变 vs 不可变 + 参数传递

- [x] 实验：`a = [1]; b = a; b.append(2); print(a)` —— 为什么 `a` 也变了？
- [x] 实验：把一个 list 传进函数里 `.append`，函数外的 list 也变了，理解"传对象引用"。
- [x] 对照：int / str / tuple 不可变，list / dict / set 可变。

- 记录：写 3 句话解释"Python 传参到底传的是什么"。

1. Python 传参传的是对象的引用（可以理解成「贴标签」），不是把整个对象拷贝一份。
2. 函数里对可变对象做原地修改（`append`、`pop`、`d[k]=v`），调用方手里的**同一个**对象也会变。
3. 对不可变对象（`int`、`str`、`tuple`），赋值只会让局部变量指向新对象，不会改变调用方原来的那个。



### Day 3 — list / tuple + 解包

- [x] 学：`a, b, *rest = [1, 2, 3, 4]` 解包；tuple 为什么能当 dict key。
- [x] 实验：`first, *mid, last = range(5)`，打印 `mid`。
- [x] 练习：写一个函数返回多值 `return name, age`，调用方用 `n, a = f()` 接收。

- 记录：tuple 和 list 分别什么时候用？
  - **tuple**：不可变；固定结构、函数多返回值；可当 dict key（不可变 → 可哈希）。
  - **list**：可变；元素会增删改时用（如 `messages` 列表不断 `append`）。



### Day 4 — 切片

- [x] 学：`xs[start:stop:step]`、负索引、`xs[::-1]` 反转、`xs[-3:]` 取最近 3 个。
- [x] 做题 **2** `last_n`，跑通（含 n 超长的边界）。

- 记录：`xs[-3:]`、`xs[::-1]`、`xs[::2]` 分别取到什么？用自己的话写切片三参数的含义。
xs[-3:]：从倒数第 3 个到末尾（最近 3 个）
xs[::-1]：整个列表反转（step=-1）
xs[::2]：从头到尾每隔一个取一个
start 从哪开始（包含），stop 到哪结束（不含），step 每隔几个取一个；省略则用默认值。



### Day 5 — dict 惯用法

- [x] 学：`d.get(k, default)`、`d.setdefault`、合并 `{**a, **b}`、`.items()` 遍历。
- [x] 做题 **3** `get_timeout`，跑通。

- 记录：什么情况下必须用 `.get` 而不能用 `d[k]`？（对应 Agent 里解析可能缺字段的 API 响应）
当 key **可能不存在**、又不想程序崩溃时用 `.get(k, default)`；典型场景是解析 API 响应、读配置（字段可能缺失，如没有 `timeout`）。`d[k]` 在 key 不存在时会抛 `KeyError`，适合 key **必须存在**、缺了就该报错的情况。



### Day 6 — set

- [x] 学：去重、`&`/`|`/`-` 交并差、`in` 判断 O(1)。
- [x] 做题 **5** `unique_tools`，跑通。

- 记录：list 的 `in` 和 set 的 `in` 复杂度差别？（Agent 里"已访问集合"为什么用 set）
  - **list 的** `in`：O(n)，需逐个遍历比较。
  - **set 的** `in`：O(1) 平均，基于哈希表查找。
  - **Agent 用 set**：维护「已访问集合」（URL、tool、node）时会反复 `if x in visited`，数据量大时 set 远快于 list。去重用 `set(names)` 即可。



### Day 7 — 推导式 + 周复盘

- [x] 学：列表 / 字典 / 集合推导式，条件过滤 `[f(x) for x in xs if cond]`。
- [x] 做题 **4** `user_contents`，跑通。
- [x] 周复盘：把本周结论回流到 `[01-学习手册.md](./01-学习手册.md)` 的"关键结论"。

- 记录：用推导式和普通 `for` 循环各写一遍同一个过滤+转换，体会推导式的简洁。
  def user_contents(messages: list[dict]) -> list[str]:

      for m in messages:
