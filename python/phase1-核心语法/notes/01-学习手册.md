## Day 1-2：数据类型与真值

### 学习目标

- 搞懂 `None`、真值规则、`is` vs `==`、可变 vs 不可变。
- 跑通：写出 5 个你觉得反直觉的 Python 行为（如 `[] == False` 为假但 `not []` 为真）。

### 关键观察与结论

#### 1. `[] == False` 吗？`if not []:` 会进分支吗？

**结论**：`[] == False` 为 **False**（类型不同，空列表不等于布尔 `False`）；但 `if not []:` **会进分支**（空列表是假值）。`==` 比的是值是否相等，真值判断看的是 truthiness，不是一回事。`if not x:` 时，`[]`、`{}`、`""`、`0`、`None`、`False` 都会当假。

#### 2. `a = [1]; b = a; b.append(2)`，`a` 变了吗？为什么？

**结论**：**`a` 变了**，变成 `[1, 2]`。因为 `b = a` 没有复制 list，只是让 `b` 也指向同一个 list 对象；`list` 是可变类型，`b.append(2)` 会原地修改这个对象，所以 `a` 也跟着变。

#### 3. `1000 is 1000` 和 `a = 1000; b = 1000; a is b` 结果一样吗？

**结论**：`1000 is 1000` 通常为 `True`（小整数缓存）。同一行 `a = 1000; b = 1000; a is b` 也可能为 `True`（常量复用）；但 `a = int("1000"); b = int("1000"); a is b` 通常为 `False`（运行时各自创建）。`==` 比较值；`is` 比较是否同一对象。比较数值用 `==`，`is` 主要用于 `x is None`。

### 反直觉行为（目标 5 个，Day 1-2 逐步补）

1. `[] == False` 为假，但 `not []` 为真
2. 同一行 `a = 1000; b = 1000; a is b` 可能为真，分开写或用 `int("1000")` 通常为假
3. `b.append(2)` 后 `a` 也变了（同一 list 对象被原地修改）
4. `return name, age` 实际返回的是 tuple，不是两个独立值

## Day 3：list / tuple + 解包

### 学习目标

- 熟练解包（含 `*rest` 收集剩余元素）、函数多返回值。
- 能说清 list / tuple 的区别及 tuple 能当 dict key 的原因。

### 关键观察与结论

#### 1. `a, b, *rest = [1, 2, 3, 4]` 解包；tuple 为什么能当 dict key？

**结论**：`a=1`，`b=2`，`rest=[3, 4]`（`*rest` 把剩余元素收进一个 **list**）。`dict` 的 key 必须可哈希；`tuple` 不可变，可以当 key；`list` 可变，不能当 key（`TypeError: unhashable type: 'list'`）。

#### 2. `first, *mid, last = range(5)`，`mid` 是什么？

**结论**：`first=0`，`mid=[1, 2, 3]`，`last=4`。`*mid` 收的是中间所有元素，类型是 list。

#### 3. `return name, age` 和 tuple / list 分别什么时候用？

**结论**：`return name, age` 实际返回 **tuple** `("Alice", 25)`，调用方用 `n, a = f()` 解包。**tuple**：不可变，固定结构、多返回值、当 dict key。**list**：可变，会增删改的序列（如 Agent 里的 `messages`）。

## Day 4-7：切片 / dict / set / 推导式

### 学习目标

- 熟练切片、dict / set 惯用法、推导式。

### 关键观察与结论

#### 1. `xs[-3:]` 取最近 3 条；`xs[::-1]` 反转——切片三个参数 `[start:stop:step]` 分别控制什么？

**结论**（以 `xs = [0, 1, 2, 3, 4, 5]` 为例）：`xs[-3:]` → `[3, 4, 5]`（从倒数第 3 个到末尾，取最近 3 个）；`xs[::-1]` → `[5, 4, 3, 2, 1, 0]`（整表反转，`step=-1`）；`xs[::2]` → `[0, 2, 4]`（从头到尾每隔一个取一个）。
三参数：`start` 从哪开始（**含**），`stop` 到哪结束（**不含**），`step` 步长；省略则用默认值。切片不会越界，`xs[-100:]` 有多少取多少。

#### 2. `d.get(k, default)` vs `d[k]` 的区别，什么时候必须用前者？

**结论**：key 存在时，`d[k]` 和 `d.get(k, default)` 都返回值。key 不存在时：`d[k]` 抛 `KeyError`；`d.get(k)` 返回 `None`；`d.get(k, default)` 返回 `default`。**必须用 `.get`**：解析 API 响应、读配置等字段可能缺失的场景（如 `response.get("temperature", 0.7)`）。**用 `d[k]`**：key 必须存在，缺了说明程序逻辑有问题，应该报错。

#### 3. list 的 `in` 和 set 的 `in` 复杂度差别？Agent 里「已访问集合」为什么用 set？

**结论**：**list 的 `in`** 是 O(n)，要遍历每个元素。**set 的 `in`** 平均 O(1)，哈希查找。`set(xs)` 自动去重。Agent 里维护 `visited_urls`、`called_tools` 等集合，会高频 `if x in visited`，用 set 比 list 快得多。

#### 4. 推导式 `[f(x) for x in xs if cond(x)]` 和普通 `for` 循环相比，可读性差别在哪？

**结论**：两者功能等价，但适用场景不同。推导式适合「单一目标的过滤 + 转换」，写法紧凑、意图集中（如 `contents = [m["content"] for m in messages if m["role"] == "user"]`）。普通 `for` 循环在逻辑分支多、步骤多（日志、异常处理、多次修改）时更清晰。经验规则：**简单转换优先推导式，复杂流程优先 `for` 循环**。
