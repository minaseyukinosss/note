## 一、判断题（对 / 错，并一句话说明理由）

1. `def f(a, b=1, *, c): f(1, 2, 3)` 是合法调用。
2. 默认参数在**每次函数调用时**重新求值。
3. `def append_log(msg, logs=[]): logs.append(msg); return logs` 连续两次 `append_log("x")` 会各自返回 `["x"]`。
4. 用 `None` 作可变容器的默认参数是安全的，因为 `None` 是不可变单例。
5. 在 `def f(*args, **kwargs)` 里，`args` 的类型是 `list`。
6. `call_with_defaults` 在 `kwargs` 里已有 `temperature` 时，不应覆盖调用方传入的值。
7. 函数内**只读**全局变量，必须先写 `global` 声明。
8. 函数内写 `count = count + 1`，若 `count` 是模块顶层变量，不加 `global` 也能正常执行。
9. 在普通函数里写 `nonlocal obj` 后，`obj = []` 可以改掉调用方实参绑定的名字。
10. 闭包捕获的是创建时的**值快照**，外层变量后来变了，闭包仍看到旧值。
11. `funcs = [lambda: i for i in range(3)]`，执行 `[f() for f in funcs]` 得到 `[0, 1, 2]`。
12. `make_counter` 里 `return counter` 会让 `count` 立刻变成 1。
13. 装饰器底层就是闭包：外层接受函数，内层包装并返回新函数。
14. `{**a, **b}` 合并 dict 时，若 key 重复，**后面**的 dict 覆盖前面的。
15. 在 `flatten_dict` 的 `for` 循环里对嵌套 dict 分支写 `return flatten_dict(...)`，会跳过后续 sibling key。
16. 分组时写 `if m.get("role") in roles` 与 `if m.get("role") == role` 效果相同。
17. `global` 改模块顶层变量；`nonlocal` 改直接外层嵌套函数的变量。
18. `lambda i=i: i` 利用「默认参数在定义时求值」来冻结循环变量。

## 五、简答精要



### 1. 强制关键字参数 `*` 有什么用？

```python
def chat(model, temperature=0.7, *, max_tokens):
    ...
```

- `*` 之后的参数**只能用关键字传**：`chat("gpt-4", max_tokens=512)` ✅，`chat("gpt-4", 512)` ❌。
- Agent 接口里 `temperature=0.7`、`max_tokens=2048` 自解释，避免同类型参数传反；以后加参数也不破坏已有调用。



### 2. 可变默认参数陷阱


| 错误写法               | 现象             | 原因                                     |
| ------------------ | -------------- | -------------------------------------- |
| `def f(x, acc=[])` | 连续调用 acc 跨调用累积 | 默认 `[]` 在**定义时**创建一次，存入 `__defaults__` |


**正确写法**：

```python
def append_log(msg, logs=None):
    if logs is None:
        logs = []
    logs.append(msg)
    return logs
```

**Agent 后果**：`history=[]`、`messages=[]` 默认值 → 多会话 / 多请求共享同一份 list → tool 调用历史串台。

### 3. `*args` / `**kwargs`：定义处 vs 调用处


| 位置      | 写法                             | 作用                                        |
| ------- | ------------------------------ | ----------------------------------------- |
| **定义处** | `def f(a, *args, **kwargs)`    | `*args` → **tuple**；`**kwargs` → **dict** |
| **调用处** | `f(*items, **d)`               | 把序列 / dict **展开**成位置 / 关键字参数              |
| **透传**  | `return real(*args, **kwargs)` | 包装层不丢调用方参数                                |


框架里 `**kwargs` 解决：参数多且会变、包装层注入默认值、底层加新参数旧包装不用改。

### 4. LEGB 与 `global` / `nonlocal`

- **查找顺序**：Local → Enclosing → Global → Builtin。
- **只读**外层 / 全局：不用声明。
- **赋值**即创建 Local；要改 Global 写 `global`；要改直接外层写 `nonlocal`。
- `count = count + 1` 无 `global`/`nonlocal` → `UnboundLocalError`（左边已把 `count` 当 Local）。



### 5. 闭包三要素 + 晚绑定

**闭包**：① 嵌套函数 ② 内层引用外层变量 ③ 外层 `return` 内层后仍被调用。

- `return counter` 只交出函数对象，**不会**自增；自增靠外面反复调用 `c()`。
- **晚绑定**：`[lambda: i for i in range(3)]` 三个 lambda 共享**同一个** `i`，调用时 `i==2` → `[2,2,2]`。
- **修复**：`lambda i=i: i`（默认参数在定义时求值，冻结当前 `i`）。
- **与装饰器**：装饰器 = 外层变量是 `func` 的闭包；`@deco` ≡ `func = deco(func)`。



### 6. mutate vs rebind（和 Week 1 传参衔接）


| 操作                           | 外面会变吗                |
| ---------------------------- | -------------------- |
| `obj.append(1)` / `obj[k]=v` | ✅ 同一对象，内容变了          |
| `obj = []`（普通参数）             | ❌ 只改函数内局部名           |
| 嵌套里 `count += 1`             | ❌ 要 `nonlocal count` |


`nonlocal` **不能**让普通函数的 `obj = []` 改掉调用方的变量名——只能改外层嵌套函数里的 binding。

### 7. 综合题：`group_by_role` 与 `flatten_dict`

**分组**：

```python
roles = {m.get("role") for m in messages}
result = {
    role: [m.get("content") for m in messages if m.get("role") == role]
    for role in roles
}
```

条件必须是 `== role`；`in roles` 会对每个 key 都匹配「属于任意已知 role 的消息」，结果错误。

**扁平化**：

```python
if isinstance(value, dict):
    result = {**result, **flatten_dict(value, full_key, sep)}
else:
    result[full_key] = value
```

- 循环里用 `{**result, **sub}` **保留**已收集的键；只写 `{**sub}` 会覆盖 sibling。
- `return` 只放在 `for` 结束后；循环中 `return` 跳过后续 key。

## 六、场景应用精要



### 1. Agent SDK 包装：注入默认参数 + 透传

```python
def call_llm(client, *args, **kwargs):
    kwargs.setdefault("temperature", 0.7)
    kwargs.setdefault("max_tokens", 2048)
    return client.chat(*args, **kwargs)
```

调用方已传 `temperature=0.3` 时，`setdefault` / `not in kwargs` 检查都不应覆盖。

### 2. 会话状态：绝不用可变默认值

```python
# ❌ 多用户串台
def run_agent(messages=[]):
    ...

# ✅
def run_agent(messages=None):
    if messages is None:
        messages = []
```



### 3. 装饰器预演（阶段二会正式学）

```python
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper
```

`wrapper` 通过闭包记住 `func`；`*args, **kwargs` 保证包装后参数签名不变。

### 4. 展平嵌套 tool 参数 / JSON 配置

```python
flatten_dict({"tools": {"search": {"top_k": 5}}, "model": "gpt-4"})
# → {"tools.search.top_k": 5, "model": "gpt-4"}
```

Agent 里读 `config.get("tools.search.top_k", 3)` 前，常需先把嵌套 dict 展平或改用多级 `.get`。

## 七、复盘总结（本次测试易错点）


| 知识点           | 易错表现                       | 正确理解                                |
| ------------- | -------------------------- | ----------------------------------- |
| 强制关键字 `*`     | 以为 `f(1, 2, 3)` 可以传 `c`    | `*` 后必须 `c=3`                       |
| 可变默认参数        | 以为每次调用新建 `[]`              | 定义时求值一次；用 `None` 哨兵                 |
| `*args` 类型    | 以为是 list                   | 定义处收集为 **tuple**                    |
| LEGB 赋值       | 只读也要 `global`              | 只有**赋值**才需要；`count += 1` 算赋值        |
| `nonlocal` 范围 | 以为能改调用方实参                  | 只改**外层嵌套函数**的变量                     |
| 闭包 return     | 以为 `return counter` 会自增    | 自增靠**调用** `c()`                     |
| 晚绑定           | 以为 lambda 捕获创建时的值          | 捕获**变量绑定**；用 `i=i` 冻结               |
| 分组条件          | `in roles` 和 `== role` 混用  | 必须 `== role` 匹配当前分组                 |
| 递归合并          | 循环里 `return` 或漏 `**result` | 累加用 `{**result, **sub}`；return 放循环外 |

### 四、手写代码参考

```python
def append_log(msg, logs=None):
    if logs is None:
        logs = []
    logs.append(msg)
    return logs

def call_with_defaults(func, *args, **kwargs):
    if "temperature" not in kwargs:
        kwargs["temperature"] = 0.7
    return func(*args, **kwargs)

def make_counter():
    count = 0
    def counter():
        nonlocal count
        count += 1
        return count
    return counter

def flatten_dict(d, parent_key="", sep="."):
    result = {}
    for key, value in d.items():
        full_key = f"{parent_key}{sep}{key}" if parent_key else key
        if isinstance(value, dict):
            result = {**result, **flatten_dict(value, full_key, sep)}
        else:
            result[full_key] = value
    return result
```
