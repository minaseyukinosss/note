## Week 4：面向对象 + 抽象接口（Day 22-28）

### Day 22 — `self` + `__init__` + 类属性 vs 实例属性

- [x] 读本阶段 [`../README.md`](../README.md)「本阶段解决什么问题」+ 学习顺序第 1 条。
- [x] 实验：写一个 `Counter` 类，`__init__` 里 `self.n = 0`，`inc` 里 `self.n += 1`；建两个实例验证互不影响。
- [x] 实验：`class Bag: items = []`，两个实例分别 `append`，观察是否共享；再改成 `self.items = []` 对比。
- [x] 做题 **O1** `Counter`（见 `exercises.py`），取消断言跑通。

- 记录：类属性 vs 实例属性各写一句话；可变类属性的坑用自己的话再说一遍。
  - 类属性：类体一份、默认共享；实例属性：`self.xxx`，每实例独立。
  - 可变类属性（如 `items = []`）被 `append` 会改到所有实例；状态用 `__init__` 里新建。
  - **学了什么**：`self` 是当前实例；共享用类属性、对象自己的状态在 `__init__` 新建；可变类属性会串台。

### Day 23 — `@classmethod` / `@staticmethod`

- [x] **先读/跟敲**（不要空想）：把下面「三种方法」最小例子在 REPL 里敲一遍，看懂输出再往下。
- [x] 跟敲后只改一处：给 `Box` 再加一个 `@classmethod` 名叫 `from_dict`，接收 `{"label": "..."}`，内部 `return cls(data["label"])`，调用 `Box.from_dict({"label": "c"})` 验证。
- [x] 跟敲里的 `@staticmethod is_empty_label` 已够用；想加深再自己写一个 `normalize_label(s) -> str`（`strip` + 小写），仍不依赖 `self`/`cls`。
- [x] 做题 **O2** `Message.from_dict`：与上面 `from_dict` 同构，只是字段变成 `role`/`content`；取消断言跑通。

- 记录：`cls` vs `self`；classmethod 为何用 `cls(...)` 不写死类名；staticmethod 和模块函数差在哪。
  - 决策：已有对象要干活 → 实例方法；还没有对象、要从 dict/配置造 → classmethod；和类无关的纯函数 → 模块函数（少用 staticmethod）。
  - 「从 dict 造」= 把现成字典翻译成对象，不是 dict 有魔法。
  - 工厂里 `cls(...)` **仍会走 `__init__`**，不是绕过；只是先拆参数再初始化。
  - 子类没写 `from_dict` 也能调（继承）；`cls` 是调用时的类，所以必须 `cls(...)` 才能造出子类。
  - **学了什么**：三种方法怎么选（实例干活 / 类方法从 dict 造 / 静态≈模块函数）；工厂仍走 `__init__`；`cls(...)` 是为了子类调用时造出子类。

### Day 24 — 单继承 + `super()`

- [x] **先读/跟敲**：`Animal` / `Dog` 两段（有 `super()` vs 删掉 `super()`），看 `dog.species` 还在不在。
- [x] 确认：子类没写的方法会去父类找（Day 23 的 `ToolMessage.from_dict` 就是这件事）。
- [x] 做题 **O3** `EchoTool`：`__init__` 里 `super().__init__("echo")`；`run` 返回 `f"echo:{query}"`；取消断言跑通。

- 记录：子类重写 `__init__` 时为什么几乎总要调 `super()`；单继承时 `super()` 就是父类。
  - 自己写了 `__init__` 就不会自动跑父类那份，不 `super()` 父类字段会丢。
  - 不写子类 `__init__`：能拿到父类字段，但没有子类额外属性，构造也跟父类一样。
  - **学了什么**：继承会去父类找方法；覆盖 `__init__` 必须 `super()`；单继承里 `super()` = 父类。

### Day 25 — 多继承 + MRO

- [x] **先读/跟敲**：打印 `D.__mro__`，确认顺序是 `D, B, C, A, object`。
- [x] **跟敲**：四个类的 `__init__` 都 `print` + `super().__init__()`，看打印顺序；对照「不调 super、B/C 直接调 A」会怎样。
- [x] 做题 **O4**：取消断言，确认你能说出为什么是 `["D", "B", "C", "A", "object"]`。

- 记录：MRO 是查找清单；`super()` 走清单上下一个，不是「那个父类」；钻石里 A 为何只初始化一次。
  - `D(B, C)` → `D, B, C, A, object`；B 在 C 前因为括号里 B 写在左边。
  - `object.__init__` 是空收尾；A 的 `super()` 交给它。钻石里 A 可不写，多继承习惯上每个 `__init__` 都写。
  - **学了什么**：MRO 是查找清单；`super()` 走下一个；钻石 + 人人 `super()` 则 A 只初始化一次。

### Day 26 — `ABC` + `@abstractmethod`

- [x] **跟敲 1**：`BaseMemory()` 直接实例化，看报错类型。
- [x] **跟敲 2**：空子类 `class Bad(BaseMemory): pass` 再 `Bad()`，确认同样不能实例化。
- [x] 做题 **O5** `ListMemory`：内部 list；`add` append；`get` 返回副本；取消断言跑通。

- 记录：漏实现抽象方法时报什么错；ABC 比「文档里约定接口」多了什么。
  - 报 `TypeError`，`类名()` 就拦下；不是调用时才 `NotImplementedError`。
  - 抽象类可以有 `__init__` 和普通方法；`_items` 是子类自己起的实例属性名。
  - **学了什么**：有 `@abstractmethod` 就不能对该类 `()`（和有没有方法体无关）；子类补完洞才能 `()`；要算实现接口必须写 `class Xxx(BaseMemory)`。
