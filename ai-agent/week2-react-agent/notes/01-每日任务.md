## Day 10-12：手写 ReAct 循环

**目标**：补完并跑通 `react_agent.py`。

```bash
cd ai-agent
source .venv/bin/activate
python week2-react-agent/code/react_agent.py
```

观察：

- `messages` 如何从 `system → user` 变长。
- 每次 assistant 是否带 `tool_calls`。

- 最后一条 assistant 为什么没有 `tool_calls`。

必须跑的用例：

- 北京天气。
- 北京天气 + `23 * 47`。
- `100 / 0`。
- 订机票。

## Day 13-14：主动制造失败

**目标**：理解模型不可控性，形成 Week3 对比基线。

实验：

- `max_steps=1`。
- 5 步以上长链任务。
- 同一轮多个工具调用。
- 要求“必须计算器算”，观察模型是否心算跳过。
- 问无合适工具的问题。

记录：

- 哪一步开始偏？
- 是 prompt 问题、工具 description 问题，还是应该改成 workflow？
- 框架能解决这个问题吗？

详细记录统一整理在 [04-过程记录](./04-过程记录.md#day-13-14主动制造失败)。
