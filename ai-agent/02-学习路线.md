# AI Agent 学习路线

## 总览

学习路径分 7 个阶段，从底层原理 → 工具调用 → Workflow / Agent 分界 → 图编排 → RAG / 记忆 → 评估与安全 → 综合实战。建议节奏：每阶段 1-2 周，总计 8-12 周。

```text
阶段 0  前置准备     →  阶段 1  Prompt 与工具调用
                              ↓
阶段 2  Workflow / Agent 范式  →  阶段 3  图编排与可观测
                              ↓
阶段 4  RAG / 记忆  →  阶段 5  评估、安全与上线
                              ↓
                  阶段 6  综合项目
```

## 与 3 周入门项目的关系

当前仓库的 Week1-Week3 是这条长期路线的入门压缩版：

| 入门项目 | 对应长期阶段 | 学完后应该具备的能力 |
| --- | --- | --- |
| Week1：LLM 调用与 Function Calling | 阶段 0-1 | 能解释 `messages`、token、tool call 协议，并跑通两轮工具调用。 |
| Week2：手写 ReAct Agent | 阶段 2 | 能写出最小 Agent 循环，知道 Agent 与 workflow 的边界。 |
| Week3：LangGraph + checkpoint + trace | 阶段 3 | 能把裸写循环迁移到 StateGraph，理解 state / node / edge / checkpointer / trace。 |
| Week4：RAG + 引用 + eval | 阶段 4-5 的前半 | 能把检索封装成工具，先用 W4-001 ~ W4-003 验收召回、引用和未命中，再扩展矛盾片段、安全和自动评估。 |

完成 Week3 后，不建议立刻横向追很多框架。更好的下一步是进入阶段 4：给已有 Agent 增加 RAG、引用来源和评估用例。

## 入门路线的工程校准

对新手来说，最容易走偏的地方有 4 个：

1. **把 RAG 和 Memory 混为一谈**：RAG 是外部知识检索工具；Memory 是跨轮 / 跨会话状态管理。入门阶段先做 RAG，再谈长期记忆写入策略。
2. **太晚做评估**：从 Week2 开始就要维护固定用例，否则每次改 prompt / 模型 / 工具都只能凭感觉。
3. **过早追多 Agent**：多 Agent 会放大 token、延迟和调试成本。单 Agent 的工具、状态、trace 没打牢前不要碰。
4. **忽视工具安全**：读工具、写工具、外部副作用工具必须分级；文件写入、发邮件、下单、转账这类动作需要 dry-run 或人工确认。

## 阶段 0：前置准备（3-5 天）

**目标**：扫清语言与 API 障碍。

- Python：async/await、`pydantic`、`typing`。
- 一次性跑通 OpenAI / Anthropic / DeepSeek 任一 API，包括：
  - 普通对话
  - Streaming
  - Function Calling / Tool Use
- 了解 token、context window、temperature、top_p 这些基础旋钮。

**产出**：一个 `hello-llm.py`，能稳定调通 API 并打印 token 使用量。

## 阶段 1：Prompt 与工具调用（1 周）

**目标**：理解 LLM 是如何"做事"的——本质是文本接龙 + 工具回调。

- Prompt 技巧：Zero-shot、Few-shot、Chain-of-Thought (CoT)、Self-Consistency。
- Function Calling 的协议层细节（OpenAI / Anthropic 各自的 JSON schema）。
- 工具设计：命名、描述、参数 schema、错误返回、权限边界。
- 区分单次 LLM、augmented LLM、workflow、agent。

**产出**：
- 不用任何框架，写一个 **tool calling demo**：模型决定是否调用 1-2 个工具（如计算器、天气），程序负责执行工具并把结果塞回上下文。
- 这一步是后续 ReAct / LangGraph 的"协议基石"，必须亲手写过。

**关键资料**：
- 论文：[ReAct: Synergizing Reasoning and Acting in Language Models](https://arxiv.org/abs/2210.03629)
- 博客：Anthropic [Building Effective Agents](https://www.anthropic.com/research/building-effective-agents)

## 阶段 2：Workflow / Agent 范式（1-2 周）

**目标**：横向了解主流 agentic system 设计模式，知道何时用 workflow，何时才需要 agent。

| 范式 | 核心思想 | 代表论文 |
| --- | --- | --- |
| ReAct | 推理与行动交替 | ReAct (2022) |
| Plan-and-Execute | 先全局规划，再分步执行 | Plan-and-Solve (2023) |
| Reflection | 执行后自我批评、修正 | Reflexion (2023) |
| Tree of Thoughts | 思维树搜索 | ToT (2023) |
| Multi-Agent | 多角色协作 / 辩论 | AutoGen / MetaGPT |

**产出**：
- 不用任何框架，**手写一个 ReAct Agent**（≤ 200 行），能调用 1-2 个工具（如计算器、搜索）。
- 每种范式写一段 ≤ 100 字的笔记，说明"适用场景 / 不适用场景"（见 [03-核心概念](./03-核心概念.md)）。

## 阶段 3：图编排与可观测（1-2 周）

**目标**：选 1 个图编排框架吃透，把手写 ReAct 改造成可恢复、可观测、可测试的工程结构。

**推荐主修**：
- **LangGraph**（基于状态图，工程化最完整）—— 首选。
- 轻量备选：**OpenAI Agents SDK**（官方 SDK，handoff / guardrail / tracing 直接）。
- 多 Agent 备选：**AutoGen**（多 Agent 对话强）、**CrewAI**（角色分工直观）。

**了解即可**：
- LangChain v1 `create_agent`（轻量起步可以用；复杂状态优先 LangGraph）
- LlamaIndex（偏 RAG / 数据接入）
- Swarm（OpenAI 早期实验项目，了解历史即可）

**产出**：用 LangGraph 复刻阶段 2 的 ReAct Agent，并扩展为支持：
- 多工具
- 检查点（checkpointer）持久化
- trace 可观测性
- 最小 human-in-the-loop：敏感工具调用前先输出待确认动作，而不是直接执行

## 阶段 4：记忆与 RAG（1-2 周）

**目标**：先让 Agent 会可靠检索外部知识，再讨论长期记忆。

- **RAG 基本链路**：切分（chunking）→ 嵌入（embedding）→ 检索（retrieval）→ rerank / 过滤 → 带引用生成。
- 向量库：Chroma（本地起步）、Qdrant / Pinecone（生产）。
- 进阶检索：Hybrid Search、Rerank、HyDE、Multi-Query。
- 记忆设计：短期（对话窗口）、长期（向量库 / 数据库）、Episodic / Semantic / Procedural 区分。
- 上下文工程：哪些历史保留、哪些摘要、哪些检索、哪些必须从上下文剔除。

**产出**：
- 给阶段 3 的 Agent 加一个"私有知识库"工具（向量检索），回答必须返回引用来源。
- 先跑通 3 条必做 RAG 用例：召回、引用、未命中。
- 再扩展到 10-20 条 RAG golden cases，记录“检索是否召回、引用是否正确、答案是否幻觉”。

## 阶段 5：评估、安全与上线（1 周）

**目标**：从 Demo 到能信任的系统。

- Tracing：[LangSmith](https://smith.langchain.com/) / [Langfuse](https://langfuse.com/) 任选其一。
- Eval：
  - 单步评估：工具调用是否正确、参数是否对。
  - 端到端评估：用 LLM-as-Judge 打分。
  - 数据集：自己造 20-50 条 golden case。
- 安全：Prompt Injection 防御、工具白名单、超时与重试。
- Guardrails：输入校验、输出结构校验、敏感动作审批、工具权限分级。
- 成本与延迟：token 预算、模型路由（强/弱模型分工）。

**产出**：一份"上线 checklist" + 一个跑通的 trace 链路 + 一份失败案例复盘。

## 阶段 6：综合项目（2-3 周）

挑 1 个方向深做，能写出 README + 演示视频。

候选项目：

1. **研究 Agent**：输入主题 → 自动检索、总结、生成结构化报告。
2. **代码 Agent**：类 Cursor / Aider 的最小版，能读写本地文件并跑测试。
3. **浏览器 Agent**：基于 Playwright，自动完成"订机票/查快递"等任务。
4. **客服 Agent**：接入私有 FAQ + 工单系统，能处理多轮咨询。

**评分维度**：
- 任务完成率（在你的 golden set 上）
- 平均 token 成本
- P95 延迟
- 失败可观测性（trace 是否清晰）

## 学习节奏建议

- 每个阶段结束时，写一篇 ≤ 500 字的复盘到 `notes/` 下（命名如 `阶段3-复盘.md`）。
- 每周至少跑通 1 个能 demo 的小程序，避免只读不写。
- 卡住时先看 trace，再翻文档，最后看源码——不要直接问 LLM 要答案。
