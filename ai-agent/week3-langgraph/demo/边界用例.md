# 边界用例

> 来源：`python week3-langgraph/code/checkpoint_amnesia_demo.py`

## 用例：换 thread_id 后 checkpoint 隔离（失忆）

**脚本：** `checkpoint_amnesia_demo.py`

**输入：**

```
第 1 轮（thread=amnesia-A）：北京今天天气怎么样？
第 2 轮（thread=amnesia-B，换了 thread_id）：那上海呢？
```

**预期：**

- 第 2 轮 `messages` 里**没有**第 1 轮「北京」相关记录
- 即使最终回答看起来合理（mock 天气都是 25°C），也算「失忆」——因为新 thread 读不到旧 history
- 第 2 轮 messages 通常只有 4 条左右，从「那上海呢？」起算

**实际：**

```
第 1 轮（thread=amnesia-A）回答:
北京今天天气晴朗，气温 25°C，湿度 40%……

第 2 轮（thread=amnesia-B）回答:
上海今天天气晴朗，气温 25°C，湿度 40%……

--- 第 2 轮 messages 全量 ---
  [0] human: 那上海呢？
  [1] ai: 好的，我来查一下上海的天气。
  [2] tool: 上海 今天晴，气温 25°C，湿度 40%。
  [3] ai: 上海今天天气晴朗，气温 25°C，湿度 40%……
```

**结论：**

- Pass：第 2 轮 messages 共 **4 条**，**不含「北京」**，说明换 `thread_id` 后读不到 thread A 的 checkpoint
- 第 2 轮模型把「那上海呢？」当成独立新问题，重新调了 `get_weather(city="上海")`，符合失忆预期
- ⚠️ 若只看最终回答（两城都是 mock 25°C），容易误以为「有记忆」——**必须以 messages 条数和内容为准**
