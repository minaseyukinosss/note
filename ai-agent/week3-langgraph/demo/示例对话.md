## 用例 2：续聊追问来源

**输入：**

```
刚才那条新闻的来源是什么？
```

**输出：**

```
刚才那条新闻的主要来源是**新华社**于2026年2月3日发布的特稿：

> **《特稿丨人工智能促变革 美企滥用引风波——2026年首月全球AI产业动态》**

文中明确提到：

> **"中国企业国星宇航1月26日在一个研讨会上表示，该公司已把Qwen3大模型部署至'星算'计划01组太空计算中心。"**

此外，关于**欧盟调查X平台（Grok）** 的消息，来源是 **Reddit 上的一篇帖子**，该帖子引用了相关外媒报道：

> **"一分钟每日AI新闻2026年1月26日"** — 其中提到：*"欧盟调查X，因其未能遏制非法Grok AI内容。"*

所以，今天这条新闻的核心信息来源是：
1. **新华社**（官方权威媒体）—— 国星宇航将大模型部署至太空
2. **Reddit / 外媒综合报道** —— 欧盟对Grok的调查、微软芯片发布等
```
