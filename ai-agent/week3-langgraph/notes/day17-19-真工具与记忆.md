# Day 17-19：真工具与记忆

## 背景 / 学习目标

- 在 LangGraph Agent 上接**至少一个真工具**（搜索或读文件）。
- 用 **Checkpointer**（`SqliteSaver`）实现跨轮对话：同一 `thread_id` 续聊。
- 理解：记忆 = 持久化的 state（主要是 `messages`），不是模型自带记忆力。

## 今日操作

### 1. 先跑通 Checkpointer 示例

仓库已提供最小示例 [`../code/checkpoint_demo.py`](../code/checkpoint_demo.py)：

```bash
cd ai-agent/week3-langgraph/code
python checkpoint_demo.py
```

预期：

- 第 1 轮问「北京天气」→ 正常回答。
- 第 2 轮只问「那上海呢？」→ 应调用 `get_weather(上海)`，而不是懵掉。

原理：`thread_id` 相同 → 从 SQLite 读出上一轮 `messages` → 只 append 新的 `HumanMessage`。

### 2. 裸写 vs Checkpointer

| 自己写 | LangGraph Checkpointer |
| --- | --- |
| 每轮结束 `json.dump(messages)` 到文件 | `compile(checkpointer=SqliteSaver(...))` 自动存 |
| 下次读文件拼回 list | `invoke(..., config={"configurable": {"thread_id": "..."}})` |
| 自己处理并发、版本 | 框架提供 checkpoint 语义（学习阶段够用） |

### 方案 B：本地读文件

适合「代码 Reviewer」类 Demo（Day 20-21 可复用）。

```python
from pathlib import Path

ALLOWED_DIR = Path(__file__).resolve().parent / "sandbox"

@tool
def read_file(filename: str) -> str:
    """读取 sandbox 目录下的文本文件内容。filename 仅为文件名，不含路径。"""
    path = (ALLOWED_DIR / filename).resolve()
    if not str(path).startswith(str(ALLOWED_DIR.resolve())):
        return "错误：不允许访问 sandbox 外路径"
    if not path.is_file():
        return f"错误：文件不存在 {filename}"
    return path.read_text(encoding="utf-8")[:8000]
```

在 `code/sandbox/` 放 1～2 个 `.txt` / `.py` 样例供 Agent 读。

## Checkpointer 接入你自己的图

[`checkpoint_demo.py`](../code/checkpoint_demo.py) 核心三行：

```python
checkpointer = SqliteSaver(sqlite3.connect("checkpoints.db", check_same_thread=False))
graph = build_graph().compile(checkpointer=checkpointer)
graph.invoke(state, config={"configurable": {"thread_id": "user-123"}})
```

**要点**：

- `build_graph()` 不要全局 `compile()` 两次混用；checkpoint 版单独 `compile(checkpointer=...)`。
- `checkpoints.db` 勿提交 Git；可在 `ai-agent/.gitignore` 确认 `*.db` 已忽略。
- 生产会用 Postgres / Redis；学习阶段 SQLite 足够。

## 验收

- [ ] 同一 `thread_id` 第二轮能利用上一轮上下文。
- [ ] 至少一个工具返回**真实外部数据**（Tavily 结果或磁盘文件内容）。
- [ ] 能口头解释：Checkpointer 存的是 **state 快照**，不是模型权重。

## 易错点

| 现象 | 对策 |
| --- | --- |
| 第二轮像失忆 | `thread_id` 变了；或没 `compile(checkpointer=...)` |
| 工具报 Key 错 | `.env` 缺 `TAVILY_API_KEY`；或未重启进程 |
| 读文件路径穿越 | 必须 resolve 后校验前缀在 `sandbox` 内 |
