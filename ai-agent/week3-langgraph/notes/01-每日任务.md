# Week3 每日任务

## Day 15-16：LangGraph 重写

**目标**：用 StateGraph 复刻 Week2 同一 Agent。

```bash
cd ai-agent
source .venv/bin/activate
python week3-langgraph/code/langgraph_agent.py
```

观察：

- `agent` node 什么时候返回 tool_calls。
- `tools` node 如何生成 ToolMessage。
- `route_after_model` 如何决定去 `tools` 还是 `END`。
- `recursion_limit` 和 Week2 `max_steps` 有什么不同。

记录：

- state / node / edge 分别对应 Week2 的哪段代码？
- LangGraph 少写了哪些样板？
- 模型跳过工具的问题有没有消失？

详细记录统一整理在 [04-过程记录](./04-过程记录.md#day-15-16用-langgraph-重写-react)。

## Day 17-19：真工具与 Checkpointer

**目标**：接一个真实但低风险的工具，并验证同一 `thread_id` 能续聊。

```bash
cd ai-agent
source .venv/bin/activate
python week3-langgraph/code/checkpoint_demo.py
python week3-langgraph/code/checkpoint_amnesia_demo.py
```

观察：

- 同一 `thread_id` 第二轮是否能引用上一轮上下文。
- 换 `thread_id` 后 messages 是否隔离。
- Tavily search 是否返回真实外部数据。
- 工具失败时 observation 是否清楚。

记录：

- Checkpointer 存的是什么？
- 为什么不能只看最终回答判断“有没有记忆”？
- 真工具带来了哪些权限和可信度问题？
- 外部搜索 / 文件内容里如果出现指令，为什么不能照做？

详细记录统一整理在 [04-过程记录](./04-过程记录.md#day-17-19真工具与-checkpointer)。

## Day 20-21：Demo 交付

**目标**：选一个小场景，做成可演示、可 trace、可评估的 Agent Demo。

候选：

- 每日科技新闻摘要。
- 个人记账助手。
- 简易代码 Reviewer。

交付：

- Demo 脚本。
- README 或交付记录。
- 3 条示例对话。
- 至少 1 条 trace。
- 至少 1 条失败或边界用例。
- 至少 2 条 `05-评估用例.md` 的运行记录。

详细记录统一整理在 [04-过程记录](./04-过程记录.md#day-20-21demo-交付)。
