# AI Agent 小白入门：3 周到第一个能跑的 Agent

> 目标读者：**没写过 LLM 调用、对 Agent 完全没概念**。读完跟着做，3 周内能交付一个可演示的 ReAct Agent。

## 心态先摆正

1. **不要先啃论文**。论文是地图，但你现在连指南针都没有，先跑通代码再回头看会顺得多。
2. **不要一上来就学 LangChain / LangGraph**。框架是抽象，抽象建立在"你已经知道它在帮你做什么"之上。先裸写，再用框架，体感差 10 倍。
3. **不要追新**。Agent 领域每周都有新论文新框架，前 3 周只看本文列出的东西，其他一律不看。
4. **每天写一段 ≤ 100 字的笔记**，记"我今天搞懂了什么 / 还卡在哪"。卡点会随时间变化，写下来一周后回看会很有收获。

## 第 1 周：理解 LLM 是什么（不是什么）

**目标**：把 LLM 当成一个"会聊天 + 能输出 JSON"的函数来用，不要神化。

### Day 1-2：第一次调用 + 理解角色

读：[OpenAI Chat Completions 文档](https://platform.openai.com/docs/guides/text-generation)（前 1/3 即可）。

跑仓库里的示例（建议先读 `hello.py` 源码，再运行）：

```bash
cd ai-agent/week1-hello-llm/code
python hello.py
```

笔记模板：[`week1-hello-llm/notes/day1-学习笔记.md`](./week1-hello-llm/notes/day1-学习笔记.md)

产出：能稳定打印结果和 token 数。

**理解要点**（写进笔记）：
- `system` / `user` / `assistant` 三种角色分别是什么？
- 为什么 LLM 调用是无状态的？多轮对话靠什么？（答：把历史 messages 全发回去）
- token 是字符吗？（不是，中文一个字常常 1-2 token）

### Day 3-4：多轮对话 + Prompt 基础

运行多轮对话示例，再对照源码理解 `messages` 列表如何累积：

```bash
python chat.py
```

（`chat.py` 已实现 REPL；你也可以在它基础上改 system prompt、加 Few-shot。）

实验三件事：
1. 改 `system` prompt，让它扮演不同角色（律师 / 程序员 / 杠精），观察输出差异。
2. 把 `temperature` 从 `0` 调到 `1.5`，看回答稳定性变化。
3. 用 Few-shot：在 messages 里塞 2-3 个示例对话，看是否会模仿格式。

**理解要点**：Prompt = LLM 的全部输入。你能做的只有"改输入"，不要幻想"调参数"。

### Day 5-7：Function Calling（这是 Agent 的命门）

读：[OpenAI Function Calling 指南](https://platform.openai.com/docs/guides/function-calling)。

运行完整 Function Calling 示例（两轮请求：选工具 → 执行 → 最终回答）：

```bash
python function_calling_demo.py
```

对照 `function_calling_demo.py` 源码，重点看：
- 第 1 轮 `tool_calls` 不为空时你在做什么；
- `role: tool` 消息如何挂到 `messages`；
- 第 2 轮为何还要带上 `tools=`。

**这一步必须亲手跑通且理解**。卡住就反复看终端打印的 `tool_calls` 与 `observation`。

产出：能让 LLM 调用至少 1 个假工具，并基于工具返回值生成最终答复。

**第 1 周结束自测**（口头答出来）：
- LLM 调用工具的本质是什么？（答：LLM 不会真调工具，它只是输出一段结构化 JSON 告诉你"我想调"，由你去执行。）
- 多轮工具调用的 `messages` 长什么样？

## 第 2 周：手写你的第一个 ReAct Agent

**目标**：不用任何框架，纯 `openai` SDK 写出一个 Agent 循环。这是整个学习中最关键的一周。

### Day 8-9：读懂 ReAct（只读 1 篇博客）

只看这一篇：[Anthropic - Building Effective Agents](https://www.anthropic.com/research/building-effective-agents)。

带着这两个问题读：
- 文中说的 "augmented LLM" 是什么意思？
- "Workflow" 和 "Agent" 的区别是什么？

ReAct 一句话总结：**让 LLM 在 while 循环里反复"思考 → 调工具 → 观察结果"，直到它说"我不需要再调工具了"为止。**

### Day 10-12：手写 ReAct Agent

需求：写一个能回答**"北京今天天气，再帮我算 23 × 47"**这种**多步**问题的 Agent。

需要两个工具：
- `get_weather(city)` — 假数据即可
- `calculator(expression)` — 直接 `eval` 表达式（生产别这么干，练习无所谓）

核心循环骨架（你要补完）：

```python
def run_agent(user_input: str, max_steps: int = 6) -> str:
    messages = [
        {"role": "system", "content": "你是个能调用工具的助手。完成任务后直接回答用户。"},
        {"role": "user", "content": user_input},
    ]
    for step in range(max_steps):
        resp = client.chat.completions.create(
            model="deepseek-chat", messages=messages, tools=tools,
        )
        msg = resp.choices[0].message
        messages.append(msg)

        if not msg.tool_calls:
            return msg.content                # LLM 给出最终答案

        for call in msg.tool_calls:
            result = dispatch(call.function.name, call.function.arguments)
            messages.append({
                "role": "tool",
                "tool_call_id": call.id,
                "content": result,
            })
    return "超过最大步数，未完成"
```

**练习要求**：
1. 每一步把 `messages` 打印出来，亲眼看 LLM 是怎么"思考"的。
2. 故意让计算器抛异常（比如除以 0），看 Agent 怎么恢复——它应该会调整参数重试或直接告诉你算不出来。
3. 加第三个工具：`search(query)`，假数据返回一段固定文本。让 Agent 自己决定先查天气还是先搜索。

### Day 13-14：复盘 + 主动制造问题

故意挑战这些场景，看你的 Agent 是怎么挂的：
- 问一个**没有合适工具**的问题（"帮我订机票"）→ 它应该礼貌承认能力不足，而不是瞎编。
- 问一个**需要 5+ 步**的问题，观察是否会陷入无意义循环。
- 把 `max_steps` 改成 1，看会发生什么。

写一篇复盘笔记（≤ 500 字），记录：
- 我现在理解的 Agent 本质是什么？
- 裸写时最难的部分是什么？（多半是工具结果格式化和错误处理）
- 我希望框架帮我解决什么？（带着这个问题进入第 3 周）

> 🎯 **重要里程碑**：到这里你已经超过 80% 自称"在学 Agent"的人——他们大多直接抄 LangChain 教程，但说不清底层在干什么。

## 常见坑（提前避雷）

- ❌ 一开始就装一堆框架（LangChain + LlamaIndex + AutoGen…）→ ✅ 第 1-2 周只装 `openai` 一个包。
- ❌ Prompt 写得很长很复杂 → ✅ 先用最简单的 prompt，复杂度由工具承担，不是 prompt。
- ❌ 工具描述写得很潦草 → ✅ 工具 `description` 是 LLM 决策的唯一依据，要当成"给同事写文档"那样写。
- ❌ 出了问题就改 prompt → ✅ 先看 `messages` 全量打印，定位是哪一步出问题，再决定改 prompt / 改工具 / 改循环。
- ❌ 直接用 GPT-4o / Claude Opus 这种贵模型练习 → ✅ 用 DeepSeek 或 `gpt-4o-mini`，便宜 10 倍，够用了。
