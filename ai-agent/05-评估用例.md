# AI Agent 评估用例

> 从 Week2 开始维护。目的不是追求一次回答漂亮，而是让 prompt、模型、框架改动后能做回归对比。

## 使用方法

1. 固定输入问题，不随手改。
2. 记录预期工具调用，而不只记录最终答案。
3. 每次改 prompt、工具 schema、模型或框架后，重新跑一遍。
4. 失败时先看 trace / messages，再判断是 prompt、工具、循环还是模型问题。

## 判定标准

- **Pass**：工具选择、参数、最终答案要点都满足预期。
- **Partial**：最终答案基本对，但工具路径不符合预期，或缺少部分要点。
- **Fail**：工具误用、答案编造、循环失控、越权承诺、状态串线。

## 复盘问题

每次失败至少回答一个问题：

1. 是模型没有理解任务，还是工具描述不清楚？
2. 是工具返回格式不好，还是 observation 没写回上下文？
3. 是 Agent 本来不该处理这个任务，应该改成 workflow 或拒绝？
4. 是否需要把这个失败例子补进 `03-实验与踩坑.md`？
